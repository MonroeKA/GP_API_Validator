📊 Dashboard Template

This is a template version of the API Testing Dashboard.

Real test results will appear here after running the API scraper.

🚀 How to Generate Results:

  1. Run the API scraper: npm run scrape
  2. Select your testing mode (single endpoint or full-site crawling)
  3. Enter the API endpoint URL to test
  4. The dashboard will automatically update with your results
  5. View detailed test results including request/response data
Note: This template ensures no sensitive test data is committed to version control. The actual dashboard (results-dashboard-autoload.html) is generated dynamically with your test results.
